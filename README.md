# ツナグ先生 ― 統合校務支援（個人用）

中学校・高校の先生が、**自分の端末だけで**成績処理から所見の下書きまでを進めるための、個人用教務支援ツールです。学校のシステムには何もインストールせず、成果物（印刷物と、列マッピング付きCSV／Excel）だけを持ち込む設計にしています。

旧版（Streamlit製「ツナグ先生」V11.0）の診断をもとに、単一HTMLファイルで全面的に作り直しました。

## 設計の考え方

- **作業場所は個人端末**：ブラウザで開くだけで完結。データは端末内（ブラウザの保存領域）にのみ保存され、外部サーバーへは送られません（AI所見を使う場合のみ、本人が設定したAIサービスへ、氏名を仮名化したうえで送信します）
- **学校へ渡すのは成果物だけ**：通知表・要録の印刷物と、学校システムの様式に合わせた列マッピング付きCSV／Excel書き出し
- **入出力の主軸はExcel**：表のコピー＆貼り付けでExcelと行き来でき、CSVはShift_JIS／BOM付きUTF-8に対応

## 主な機能

- **成績処理**：評価材料を「観点への配分％＋重み」で管理。観点別A/B/Cの算出、評定は3方式（総合得点率方式／観点組み合わせ方式／**ハイブリッド方式＝既定**）。ハイブリッドは総合得点率を土台に、観点のガードルール（例：Cの観点がある生徒は評定をキャップ）で調整し、発動した生徒には印が付きます。人間調整フラグ＋理由、クラス・学年順位、評定分布、境界リスト、逆転チェック、「なぜこの評定か」の根拠表示つき
- **担当登録**：教科×学年×クラスを無制限に登録可能。評価材料の「教科ひな型」を他クラス・別学年へコピーできます
- **学年集約**：他教科の評定を取り込んで総合順位・教科バランス・配慮リストを作成
- **所見支援**：日々のメモ・スタンプの蓄積から所見文案を作成。テンプレート方式はオフラインで完結、AI方式は任意（キー設定＋氏名仮名化＋送信前プレビュー）。面談カルテつき
- **出力**：通知表・要録の汎用レイアウト印刷（プレビューつき）、月別出欠集計、列マッピング書き出し（プリセットの保存・持ち運び、書き出し前チェック）

## 使い方

`index.html` をブラウザで開くだけです。初回はセットアップガイド（年度と校種→担当の登録→名簿の取り込み）が表示されます。

## 検証について

計算ロジックは手計算と照合する単体テスト68項目にすべて合格しています（キャップ発動例・逆転検出例・同点順位の処理を含む）。詳細は `VERIFY.md`、仕様は `SPEC.md` を参照してください。

## 注意

- 本ツールは個人の端末で使う補助ツールです。評定の最終判断は必ず先生ご自身が行ってください（人間調整の仕組みはそのためにあります）
- 生徒の個人情報を扱う場合は、所属校・自治体の規定に従ってください
